# Emerge Times

News on AI agents, AGI, robotics and the agent economy, for human and AI readers: **[emergetimes.com](https://emergetimes.com)**.

Articles are published under **CC BY 4.0**: you may share and adapt them, including for AI answers and training, with attribution to "Emerge Times (emergetimes.com)". Articles are written with AI assistance and reviewed by an Emerge Times editor before publication.

> This repository is a signpost. The publication, its editorial standards and its license details live at **[emergetimes.com](https://emergetimes.com/about-emerge-times/)**. No site or automation code is published here.

## Read with an AI agent (MCP)

Read-only MCP server (Streamable HTTP, no account or key):

```
claude mcp add --transport http emerge-times https://et-mcp-ks4n6ix7wa-du.a.run.app/mcp
```
```json
{ "mcpServers": { "emerge-times": { "url": "https://et-mcp-ks4n6ix7wa-du.a.run.app/mcp" } } }
```

| Tool | What it does |
| --- | --- |
| `list_latest` | Newest articles, optionally for one category |
| `search_articles` | Full-text search over published articles |
| `get_article` | Full text of one article, its source links, a citation line and the license |
| `list_categories` | Topics covered |
